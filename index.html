METHOD

Two signals, never blended blindly

Token probability measures model choice likelihood. Claim checks measure support in the supplied source. A confident contradiction should still fail the evidence check.

HOW IT WORKS

Detect LLM hallucinations with two independent signals

Hallucination Heatmap is an open-source inspector for large language model output. It colours every token by the model’s own probability and, separately, audits each factual claim against the source you supply—so a fluent, confident answer that contradicts your documents still gets flagged.

  1. 1

    Token confidence heatmap

    Requests logprobs from any OpenAI-compatible Chat Completions API and shows exp(logprob) per token. Invented numbers, names and dates often surface as low-probability red tokens.

  2. 2

    Source-grounded claim check

    A verifier model splits the answer into atomic claims and labels each one supported, contradicted or not in source, quoting the evidence from your RAG context.

  3. 3

    Exportable trust record

    Download a hallucination-heatmap/v1 JSON with the trust score, claim verdicts and token logprobs, or call the local API from your RAG and evaluation pipelines.

Use cases

  • RAG quality assurance — catch answers that drift from retrieved policies, contracts or knowledge-base articles.
  • LLM evaluation — score batches of outputs and log claim-level verdicts next to your metrics.
  • Prompt and model comparison — see which prompt or model invents fewer unsupported statistics.
  • Reviewing ChatGPT and Claude answers — audit pasted output or use the Chrome extension on chatgpt.com and claude.ai.

Frequently asked questions

Can token logprobs detect hallucinations?

Partly. Low probability often marks guesses, but a model can be confidently wrong. That is why the claim check against your source is a separate signal and carries 70% of the trust score.

Does it work with ChatGPT or Claude?

Yes, in verifier mode: paste an answer or use the extension. Closed chat products do not expose token logprobs, so only claim-level review is available.

Is my API key exposed to the browser?

No. Keys live in a local .env file read by the Python server. The page never receives them.

Is the trust score calibrated?

No. It is a transparent heuristic for prototyping. Set your own thresholds and keep human review for legal, medical or financial decisions.
